## Quick Start

Get up and running in minutes.

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up at `https://dashboard.example.com` with your email.
  </Step>
  <Step title="Set Up Space" icon="settings">
    Create a new documentation space named "Dmitry Denisov".
  </Step>
  <Step title="Add First Page" icon="file-plus">
    Upload your `introduction.mdx` file or start from a template.
  </Step>
  <Step title="Publish" icon="globe">
    Deploy live docs at `https://docs.example.com`.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Example: Fetch docs API
  const response = await fetch('https://api.example.com/docs', {
    headers: { Authorization: `Bearer ${YOUR_API_KEY}` }
  });
  const docs = await response.json();
  console.log(docs);
  ```
  ```python
  # Example: Fetch docs API
  import requests
  response = requests.get(
      'https://api.example.com/docs',
      headers={'Authorization': f'Bearer {YOUR_API_KEY}'}
  )
  docs = response.json()
  print(docs)
  ```
</CodeGroup>

## Brand Guidelines

Maintain consistency across your docs.

Use the primary brand color `#3B82F6` for accents, buttons, and links. Pair it with neutral grays for readability.

<Tabs>
  <Tab title="CSS Example" icon="code">
    ```css
    :root {
      --brand-color: #3B82F6;
    }
    .button {
      background-color: var(--brand-color);
      color: white;
    }
    ```
  </Tab>
  <Tab title="Usage Tips" icon="info">
    - Apply to headings and icons.
    - Ensure WCAG AA contrast ratios.
    - Avoid overuse for better UX.
  </Tab>
</Tabs>
